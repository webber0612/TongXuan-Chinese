# TongXuan 前端資產需求清單

素材不是主線開發阻塞項；沒有正式素材時使用現有熊角色、CSS 圖形與 Lucide 圖示。

## P0：第一版主線

- 主角：待機、鼓勵、成功、再試一次、完成每日任務（透明 WebP／PNG）
- 課程地圖：第 0 課、入門冊、基礎冊的可替換場景背景
- 任務類型：聽音、認字、注音、拼音、筆畫、朗讀、閱讀、複習圖示
- 狀態：loading、空內容、錯誤、完成、鎖定
- 個人：兩名兒童頭像與家長頭像
- 獎勵：星星、徽章、寶箱、願望卡

## P1：完成主線後再做

- 每冊一個場景
- 每單元一個導覽角色
- 課次完成旗幟
- 連續學習與升級效果
- 可替換角色服裝與配件

## 生成規格

- 不嵌入文字，文字由前端渲染
- 不使用現成品牌、卡通角色或遊戲 IP
- 同一角色保留固定外觀、配色與比例
- 提供透明背景與 512／1024 以上尺寸
- 記錄生成工具、提示詞、日期、作者與授權狀態
- 商業版只接受 `COMMERCIAL_OK` 或已完成授權登記的資產
