# TongXuan Chinese design context

## Audience

The primary users are school-age children who do not yet understand Chinese well. They may learn Traditional Chinese with Zhuyin and Simplified Chinese with Pinyin in the same product. Parents use a separate supervisory area.

## Core use cases

- Open the app and immediately see today's small, achievable learning task.
- Move through a five-day practice sequence and a sixth-day review/BOSS checkpoint.
- Choose among recognition, handwriting, pronunciation, reading aloud, idiom, and later grammar content without losing skill separation.
- Review progress through a timeline and calendar without turning the child home into an administration dashboard.

## Desired feeling

Warm, gentle, game-like, tactile, and reassuring. The interface should feel like a polished children's learning app, not a school management system or a casino-like mobile game. Visual complexity is earned only when it helps a child understand what to do next.

## Product constraints

- React + TypeScript + Vite + vanilla CSS are the existing frontend stack; preserve them unless a task explicitly changes the stack.
- The canonical production UI is the TongXuan Web App at `/`, implemented through `frontend/src/main.tsx` and `frontend/src/AppShell.tsx`.
- Before modifying UI, follow `docs/frontend-architecture.md` to verify the production route and import chain. Historical design references are not implementation targets.
- Display language is independent from the learning script/phonetic system.
- Parent/admin features are progressive-disclosure surfaces.
- No telemetry or unnecessary permanent media storage.

## Evaluation lens

Judge every redesign by: child comprehension in two seconds, one obvious next action, comfortable reading distance, touch/mouse reachability, strong asset cropping, and whether the screen still works in grayscale.
