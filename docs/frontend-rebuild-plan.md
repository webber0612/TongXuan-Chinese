# TongXuan 前端重構計畫

## 目標

把現有前端重構成「每天會想打開的兒童中文學習 App」。官方教材決定課程順序；前端只負責讓孩子清楚知道今天要做什麼、按下開始、完成一個短任務並看到進度。

小遊戲、語音反應遊戲與額外動畫列為支線，不得阻塞主線課程流程。

## Neo Study 視覺重構契約

本輪不沿用舊版「護眼綠＋大圓角卡片＋熊角色主視覺」語言，改用獨立的產品方向：

- 深墨色 App chrome，讓內容區有明確的工作區邊界；
- 珊瑚色主任務板，黃色為主要行動與獎勵色，靛藍為學習導航色；
- 任務以編號清單、狀態列與單一主按鈕表達，不使用均等卡片堆疊；
- 兒童首頁只問一件事：「今天要做哪一個任務？」；
- 學習地圖使用課程軌道與冊次分段，來源狀態直接可見；
- 設定、家長、授權與診斷維持二級入口；
- 所有主要操作保留鍵盤焦點、觸控尺寸、loading／empty／error 狀態與 reduced-motion 支援。

本契約的驗收條件是：在首頁截圖中，不能再看到舊版綠色圓角卡片、熊角色 hero、等寬快捷卡片或舊版頁首排版。

## 唯一主線

```text
首次設定 → 入門冊（注音先／同內容拼音銜接）→ 基礎冊 → 第一冊第一課「你好」→ 今日任務 → 複習
```

主線採用僑務委員會／HuayuWorld 的《學華語向前走》課程結構。第 0 課是產品中的入門導覽，負責建立注音、拼音、聲調與基本音節的入口；它不冒充官方課文。第一冊第一課「你好」已建立官方來源入口，但精確課文、媒體與練習內容必須在完成逐項 provenance／授權登錄後才可匯入。

官方來源：<https://www.huayuworld.org/Ebook/LearnMandarinChildren>；第一冊 A：<https://www.huayuworld.org/Ebook/ebookDetail?EID=629>。

## 兒童資訊架構

兒童一級畫面只保留：

- 今天：今日任務與最大的「開始」按鈕
- 學習：目前課次與短任務流程
- 課程：官方教材冊次／單元／課次地圖
- 我的：點數、徽章、角色與個人進度

設定、顯示語言、注音／拼音顯示、字體大小、家長專區與系統診斷全部放在二級入口。家長頁面必須透過家長入口進入，不出現在兒童首頁主內容。

## 重構里程碑

1. 建立設計 token 與 App shell：手機優先、底部導覽、固定頁面標題層級、護眼色系、鍵盤與觸控可用。
2. 重做兒童首頁：今日任務置頂、單一主行動、進度路徑、獎勵摘要、清楚的 loading／empty／error／success 狀態。
3. 重做課程入口：以官方冊次、單元、課次為主，不用虛構卡片或隨機內容。
4. 建立第 0 課與第一課的垂直流程入口，接回現有 Learning API，不改寫 mastery 或後端學習邏輯。
5. 將設定、家長區、管理頁面降級為二級路由，完成 child／parent 視角隔離。
6. 以真實內容驗證：前端測試、production build、320／768／1024／1440 寬度與 reduced-motion。

## 設計拒絕項

- 不在兒童首頁放設定表單、家長報表或商業授權資訊。
- 不用大量均等卡片取代真正的任務優先級。
- 不用遊戲動畫掩蓋沒有課程內容的空畫面。
- 不將繁體／簡體或注音／拼音做成互斥的單選課程。

## 資產替換規則

先用現有熊角色、Lucide 圖示與 CSS 佔位，素材不阻塞前端實作。所有後續圖片、音效與動畫以可替換 asset key 掛接，並保留 provenance 與 usage_status。
