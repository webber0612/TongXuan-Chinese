# Repository content-rights audit — 2026-09-28

## Scope and method

This is a static source/provenance inventory refreshed against merged main baseline `4777c699412cfc49f7cef0e7a007143813d8b652` after PR #105; Issue #106 extends the candidate inventory on its active branch. It reviewed the source registry, evidence references, license boundary, lesson packages, legacy lesson data, inline learning-flow text, regression fixtures, curriculum references, child Home, lesson-facing pages, placement labels, image/font assets, and newly discovered text/media paths. It did not inspect or rewrite Git history, ingest source downloads, run semantic similarity analysis, or make a legal determination.

The official OCAC series page says it provides textbooks and downloadable text, high-resolution textbook images, audio, and teaching slide decks. This audit therefore does not treat public availability as permission to redistribute those materials. See the [official series page](https://www.huayuworld.org/Ebook/LearnMandarinChildren).

The CJK discovery range follows the current [Unicode 18.0 Chapter 18 Han block table](https://www.unicode.org/versions/Unicode18.0.0/core-spec/chapter-18/), including the Extension J block boundary U+3347F. This is only a conservative scanner boundary, not a curriculum source or rights claim; a future Unicode update may require revising the range and its regression cases.

## Classification key

- `OWNED`: item-level ownership evidence supports the recorded project use.
- `OPEN_LICENSED`: source evidence identifies an open license, and the item is within that license's scope and conditions.
- `REFERENCE_ONLY`: metadata or policy reference; not a publishable content source.
- `RIGHTS_UNCLEAR`: source, authorship, or reuse permission is not established; blocked from publishable curriculum artifacts.
- `THIRD_PARTY_RESTRICTED`: identified material whose recorded terms do not allow the proposed artifact use; blocked.

The merged mainline audit inventories 56 paths (53 `RIGHTS_UNCLEAR`, 3 `REFERENCE_ONLY`). Issue #106's branch inventory expands this to **113 tracked candidates**: **109 `RIGHTS_UNCLEAR`**, **4 `REFERENCE_ONLY`**, and none cleared as `OWNED`/`OPEN_LICENSED` or positively identified as `THIRD_PARTY_RESTRICTED`. “None identified” is not evidence that restricted material is absent. The architecture-spec branch adds one tracked CJK-bearing design reference, so this branch inventory has 114 tracked candidates: 110 RIGHTS_UNCLEAR and 4 REFERENCE_ONLY. The new specification remains blocked from publishable artifacts and is not curriculum authority. “None identified” is not evidence that restricted material is absent. The machine-readable [public-repository audit](../shared/content-sources/public-repo-audit.json) records paths, categories, source/evidence links where supported, canonical size, digest mode, and SHA-256, not file contents. Text digests normalize line endings to LF; binary files are hashed byte-for-byte. The rights gate dynamically discovers literal and escaped CJK-bearing tracked files in declared UTF-8 text extensions, through the current Unicode 18 Extension J block boundary U+3347F; it recognizes Unicode escapes (including UTF-16 surrogate pairs), numeric HTML entities, and CSS hexadecimal escapes, including the six-digit escape boundary. It inventories all declared media extensions; undecodable/NUL text-extension files are ambiguous blocked candidates, and unreadable tracked text paths cannot silently disappear from discovery. Broad discovery may include interface, technical, and reference files. It cannot detect English paraphrase, semantic copying, or authorship, and future Unicode blocks require an explicit scanner-range update. The gate fails on missing/new candidate paths, digest drift, unresolved evidence, root-MIT relicensing, and blocked files proposed for publication. All 110 unclear and 4 reference-only paths in this branch remain blocked from publishable curriculum artifacts; this does not clear or remove them from the public repository. Their public retention versus item-level proof/replacement requires an Owner decision.

## Stop-condition assessment

The tracked current tree contains a content-rich OCAC-labeled Book 1 L1 package, inline backend and frontend lesson-flow data, curriculum reference documents, and legacy data collections, but this static audit did not compare every item with source textbooks or establish copying. It found no scanned textbook pages, official audio corpus, or complete mirrored official vocabulary/question-bank dataset in the inspected file inventory. Because item-level source/authorship rights remain unresolved, none of the 109 `RIGHTS_UNCLEAR` paths may be used in publishable content. The evidence is not enough to assert either copying or non-copying; this audit is not a legal fair-use or infringement assessment.

## Audit limits and follow-up

- No complete item-by-item comparison against each source textbook or teacher handbook was performed.
- No automated paraphrase/near-duplicate detector was run; semantic similarity is not established either way.
- The Starter L1 / Basic L1 official title metadata conflict was not resolved against primary pages in this tree; both entries remain unverified pending Architect review.
- PR #105 closed the known 22-path omission by hashing blocked entries including the active `ChildPortalPage` and canonical `/learning-session` `LessonPlayerPage`; no visual or UI behavior changed. Issue #106 removes dependence on that exact-path list alone. Some generic interface/localization, phonetic, and technical files are conservatively retained as blocked entries instead of being silently omitted; exact entries carry reason and digest.
- The scan remains a path-level discovery mechanism, not a semantic corpus detector. It does not establish that text is authored, non-derivative, rights-cleared, or absent from unrecognized encodings; it cannot detect English paraphrase, copying, or authorship. Candidate discovery also produces false positives for UI, technical, and reference text. Future publishable content still requires source/item evidence and explicit authority validation.
- Rights evidence was refreshed on 2026-09-28. UTF-8 response-text SHA-256 values and byte sizes are recorded in the registry; they identify the captured representations but do not preserve their contents or prove a legal claim. Recheck current terms before ingestion or release.
- Architect should review the exact Book 1 L1 package, Starter/Basic L1 title conflict, and existing handbook paraphrase boundary before approving any derivative curriculum plan.
- This audit does not authorize deleting or rewriting existing data, changing release scope, or declaring a use lawful/unlawful.
