# Repository content-rights audit — 2026-09-28

## Scope and method

This is a static source/provenance inventory refreshed against main baseline `6ebfe71c7830bc97f9e77c91703ba15aa5fba948` after PR #103. It reviewed the existing source registry, evidence references, content-license boundary, lesson packages, legacy lesson data, inline learning-flow text, backend/frontend regression fixtures, curriculum reference documents, active child Home, lesson-facing pages, placement labels, image/font assets, and the previous audit findings. It did not inspect or rewrite Git history, ingest any source download, run a semantic similarity model, or make a legal determination.

The official OCAC series page says it provides textbooks and downloadable text, high-resolution textbook images, audio, and teaching slide decks. This audit therefore does not treat public availability as permission to redistribute those materials. See the [official series page](https://www.huayuworld.org/Ebook/LearnMandarinChildren).

## Classification key

- `OWNED`: item-level ownership evidence supports the recorded project use.
- `OPEN_LICENSED`: source evidence identifies an open license, and the item is within that license's scope and conditions.
- `REFERENCE_ONLY`: metadata or policy reference; not a publishable content source.
- `RIGHTS_UNCLEAR`: source, authorship, or reuse permission is not established; blocked from publishable curriculum artifacts.
- `THIRD_PARTY_RESTRICTED`: identified material whose recorded terms do not allow the proposed artifact use; blocked.

The machine-readable [public-repository audit](../shared/content-sources/public-repo-audit.json) currently inventories **56 tracked content-sensitive paths**: **53 `RIGHTS_UNCLEAR`**, **3 `REFERENCE_ONLY`**, and none cleared as `OWNED`/`OPEN_LICENSED` or positively identified as `THIRD_PARTY_RESTRICTED`. “None identified” is not evidence that restricted material is absent. Each entry records only the path, category, source/evidence references, canonical size, digest mode, and SHA-256; no file content is copied into the inventory. Text digests normalize line endings to LF so Windows and Linux checkouts agree; binary files are hashed byte-for-byte. Source relationships distinguish official course/title metadata from item-content authorship claims. The [rights gate](../scripts/open_curriculum_rights_gate.py) fails on missing/new candidate paths, digest drift, unresolved evidence, attempts to apply root MIT to external content, and blocked files proposed for a publishable artifact. All 53 unclear paths remain in the already-public baseline; this gate blocks their reuse in publishable curriculum artifacts but does not clear or remove them from the repository. Their public retention versus item-level proof/replacement requires an Owner decision.

## Stop-condition assessment

The tracked current tree contains a content-rich OCAC-labeled Book 1 L1 package, inline backend and frontend lesson-flow data, curriculum reference documents, and legacy data collections, but this static audit did not compare every item with source textbooks or establish copying. It found no scanned textbook pages, official audio corpus, or complete mirrored official vocabulary/question-bank dataset in the inspected file inventory. Because item-level source/authorship rights remain unresolved, none of the 53 `RIGHTS_UNCLEAR` paths may be used in publishable content. The evidence is not enough to assert either copying or non-copying; this audit is not a legal fair-use or infringement assessment.

## Audit limits and follow-up

- No complete item-by-item comparison against each source textbook or teacher handbook was performed.
- No automated paraphrase/near-duplicate detector was run; semantic similarity is not established either way.
- The Starter L1 / Basic L1 official title metadata conflict was not resolved against primary pages in this tree; both entries remain unverified pending Architect review.
- Current-tree discovery identified 22 omitted paths with embedded lesson targets, prompts/examples, course-level mappings, or curriculum-mapped regression fixtures. They now fail closed by path and digest. `frontend/src/AppShell.tsx` was inspected to confirm that `ChildPortalPage` is the active Home route; it is route evidence, not a bundled lesson-content source. `LessonPlayerPage` is the canonical `/learning-session` renderer and contains inline lesson-example and speaking-prompt fallbacks; the earlier assumption that it only consumes separately inventoried package data was incomplete, so it is now included. `ChildHomePage` was excluded because lesson targets arrive from the API. `DashboardPage` contains generic progress/admin interface copy only. `DiagnosticsPage` and its test were excluded because their fixed sample is used only for technical character-conversion/TTS diagnostics, not as a learner target or course lesson. `frontend/src/lib/ocrImport.test.ts` exercises transient user-provided OCR text fields rather than bundled lesson content. `frontend/src/lib/i18n.tsx`, `parentAuthCopy.ts`, and `chinesePhonetics.tsx` contain interface translations or generic orthographic/phonetic notation, not lesson targets. `backend/app/curriculum_policy.py` serializes titles/objectives from the separately inventoried slice and formats generic ordinals; `backend/app/reading_aloud.py` transports caller-supplied text without bundled lesson data; `backend/app/tts.py` contains script-detection character markers rather than lesson examples. This work made no visual or UI behavior changes.
- The path inventory is not a semantic corpus detector. It does not establish that every string elsewhere in the repository is authored, non-derivative, or rights-cleared; future curriculum-bearing paths must be added to the declared exact/prefix scope before use.
- Rights evidence was refreshed on 2026-09-28. UTF-8 response-text SHA-256 values and byte sizes are recorded in the registry; they identify the captured representations but do not preserve their contents or prove a legal claim. Recheck current terms before ingestion or release.
- Architect should review the exact Book 1 L1 package, Starter/Basic L1 title conflict, and existing handbook paraphrase boundary before approving any derivative curriculum plan.
- This audit does not authorize deleting or rewriting existing data, changing release scope, or declaring a use lawful/unlawful.
