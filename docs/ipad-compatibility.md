# iPad Safari compatibility matrix

The following items require a real iPad Safari test. Desktop browser results are not hardware acceptance.

| Capability | Expected | Status |
|---|---|---|
| Touch interaction | Buttons and Hanzi Writer respond to touch | `MANUAL_VALIDATION_REQUIRED` |
| Hanzi Writer | Render, animate, quiz and touch stroke input | `MANUAL_VALIDATION_REQUIRED` |
| Speech synthesis | zh-TW / zh-CN and rates 0.6 / 0.8 / 1.0 | `MANUAL_VALIDATION_REQUIRED` |
| Microphone | Permission, start, stop and playback | `MANUAL_VALIDATION_REQUIRED` |
| MediaRecorder | Temporary recording only | `MANUAL_VALIDATION_REQUIRED` |
| Audio playback | Replay and stop | `MANUAL_VALIDATION_REQUIRED` |
| API connection | HTTPS page can call NAS backend | `MANUAL_VALIDATION_REQUIRED` |
| PWA shell | Add to Home Screen and standalone mode | `MANUAL_VALIDATION_REQUIRED` |

Do not change these statuses without a real-device result.
