# Real-child Validation Protocol v1

## Purpose and status

Use this protocol to find obvious pacing, clarity, and recovery problems in the Starter / Basic / Book 1 Lesson 1 learning flow before expanding curriculum content. One or two sessions are not enough to claim educational optimization.

**Status:** protocol prepared; no real-child trial is represented as completed by this implementation. Run trials only with a parent or guardian supervising and using the product's normal child-isolation and privacy boundaries.

## Trial setup

1. Obtain parent/guardian agreement and let the child stop at any time.
2. Use a pseudonymous trial code. Do not put a child's name, school, contact information, or recording in the notes.
3. Record the placement summary and selected lesson before starting:
   - placement start: Starter, Basic, or Book 1;
   - lesson: first lesson only for v1;
   - display language and learning script mode;
   - planned target duration (15–25 minutes).
4. Confirm the parent understands that speaking and pronunciation attempts are not scored for accuracy and that session completion is separate from lesson mastery.
5. Keep the parent nearby. Do not coach answers unless the parent intentionally records the response as assisted.

## During the trial

Observe without prompting when possible. Record elapsed time from session start to exit/completion, task order, pauses, retries, hint/assisted use, optional writing phase, and whether the child asks to continue. Note visible confusion, fatigue, frustration, and what action triggered it. Do not infer pronunciation quality from the recording.

Raw microphone audio must not be collected for research or added to the trial sheet. The browser's local recording is deleted by the flow after the attempt; no recording should be copied, exported, or retained by the parent.

## After the session

The parent can inspect the minimal report/API for duration, task counts, weak domains, deferred tasks, mastery changes, and review-due counts. Compare the report with the observation sheet. Record whether the child understood the completion message and whether the parent could distinguish “practiced” from “mastered.”

Schedule follow-up checks only if the child and parent are willing:

- next-day: did the due review appear, and could the child respond independently?
- seven-day: if a seven-day review was due, did it appear and how did the child respond?

Do not turn missed follow-ups into negative learner evidence. A parent may stop the trial at any time.

## Interpretation limits

Look for repeated friction across supervised trials. Do not claim learning gains, optimized lesson length, or broad retention from a small sample. Keep product bugs, adult observations, learner self-report, and scored learning evidence separate.
